# Git & Linux Commands

- `pwd` — Shows the current directory I am in.
- `ls` — Lists the files and folders in the current directory.
- `ls -ltr` — Lists files in long format, with the oldest files first.
- `cd` — Changes to another directory.
- `mkdir` — Creates a new directory.
- `git clone` — Downloads a GitHub repository to my computer.
- `git status` — Shows the current state of my Git working area.
- `git add` — Stages changes so they can be committed.
- `git commit` — Saves staged changes as a Git commit.
- `git push` — Sends my local commits to GitHub.
- `git pull` — Gets the latest changes from GitHub and updates my local branch.
- `git branch` — Shows or manages Git branches.
- `git checkout` — Switches to another branch.
- `git log` — Shows the history of Git commits.
